# [Obsidian Themes Preview](https://ryn-cx.github.io/obsidian-theme-previews/)

Browse 100+ community themes for [Obsidian](https://obsidian.md) and instantly preview how they look using a standardized example vault. Select a theme from the dropdown to switch between them in real time.

**Try it out:** <https://ryn-cx.github.io/obsidian-theme-previews/>

## Known Issues

Theme previews are not always perfectly accurate and there may be minor visual differences.
